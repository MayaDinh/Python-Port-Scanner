# Python Port Scanner
A lightweight Python script that scans specified IP addresses for open/closed ports, using mainly the socket module.


### How do I run this script?
1. Download the file and/or clone the respository.
2. In whichever terminal you are using, navigate to the file/repository.
3. Enter the appropriate command.
    - Command Prompt: "python port_scanner.py"
    - PowerShell: "python port_scanner.py"
    - Zsh: "python3 port_scanner.py"
    - Bash/Ubuntu: "python3 port_scanner.py"
